Welcome to MojiDocs! 你的笔记以标准 Markdown 文件存储在本地。

快速开始

创建你的第一篇文档：

---
title: My First Note
tags: [hello, world]
---

# Hello MojiDocs
This is your **first** document.

所有文档自动通过 Git 同步，支持版本历史回滚。

Features
功能特性

专为知识管理设计，每个功能都经过精心打磨。

Markdown 编辑器

双栏实时预览，工具栏快捷操作，图片粘贴上传，14 种渲染主题随心切换。

全文搜索

SQLite FTS5 全文搜索引擎，关键字高亮 + 上下文片段，毫秒级响应。

Git 同步

定时 pull + push，自动冲突检测与双版本保留，支持私有仓库 PAT 认证。

树形文档管理

文件夹即目录，最近 / 全部 / 树形三种视图，拖拽导入，文档移动和置顶。

版本历史

基于 Git log 的完整版本历史，预览任意历史版本，一键回滚。

个性化定制

主题颜色自定义，字体大小调节，多种文档渲染主题（GitHub、掘金等）。
